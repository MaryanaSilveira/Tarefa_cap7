# Tarefa_cap7
Realiza o controle de um servo motor através do módulo pwm, também verifica essa variação para um led.

link do vídeo de ensaio: https://drive.google.com/file/d/1rrosBW7S1wff3Bzds-9WR4ynPVt19dUt/view?usp=sharing

Utilizar arquivos da pasta Tarefa_cap7_ para testes com servo motor.
Utilizar arquivos da pasta Tarefa_cap7_led para testes com o led.

Para o servo motor, a variação do ciclo ativo equivale numa variação da posição de sua flange, atingindo ângulos maiores para ciclos maiores. Já para o led, a variação do ciclo ativo reflete na intensidade do led, então, com ciclos mais baixos, o led permanece menos tempo ligado, aparentando ter menos brilho. Logo, quanto maior o ciclo ativo, maior a intensidade percebida do led.
